Daily Memo 개인정보처리방침

시행일: 2026-10-07

수집하는 정보

Daily Memo는 개인정보를 수집하지 않습니다. 사용자가 작성한 메모와 설정은 사용자의 브라우저 안에만 저장되며, 개발자나 제3자에게 전송되지 않습니다.

저장 위치

  • 기본: 크롬 확장 프로그램 전용 저장소(chrome.storage.local)에 저장됩니다. 사용자의 PC를 벗어나지 않습니다.
  • 동기화를 켠 경우에만: 사용자가 구글 로그인으로 허용하면, 사용자 본인의 구글 드라이브 앱 전용 영역(appDataFolder)에 메모 파일(memos.json)이 저장되고, 같은 구글 계정으로 로그인한 다른 PC의 Daily Memo가 이를 읽어옵니다. 이 영역은 Daily Memo만 접근할 수 있고 개발자는 접근할 수 없습니다.

사용 권한과 목적

  • storage, unlimitedStorage: 메모와 설정을 브라우저에 저장하기 위해 사용합니다.
  • identity: 동기화를 켠 경우 구글 드라이브 접근 토큰을 받기 위해 사용합니다. 요청 범위는 앱 전용 영역(drive.appdata)뿐이며 사용자의 다른 드라이브 파일은 보거나 수정할 수 없습니다.
  • alarms: 동기화를 켠 경우 15분마다 다른 PC의 변경을 받아오기 위해 사용합니다.
  • contextMenus: 웹페이지에서 선택한 글을 우클릭 메뉴로 오늘 메모에 추가하기 위해 사용합니다. 선택한 텍스트와 해당 페이지 주소만 메모에 기록되며 외부로 전송되지 않습니다.

외부 서비스

개발자가 운영하는 서버는 없습니다. 동기화를 켠 경우에만 구글 드라이브 API(googleapis.com)와 통신하며, 분석 도구나 광고를 포함하지 않습니다.

데이터 삭제

메모는 앱 안에서 언제든 삭제할 수 있고, 확장 프로그램을 제거하면 PC에 저장된 모든 데이터가 함께 삭제됩니다. 구글 드라이브에 동기화된 파일은 구글 계정 → 데이터 및 개인 정보 보호 → 서드 파티 앱에서 Daily Memo 연결을 삭제하면 함께 지워집니다. 백업이 필요하면 설정의 내보내기 기능으로 파일을 저장할 수 있습니다.
