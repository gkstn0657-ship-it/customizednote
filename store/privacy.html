Daily Memo 개인정보처리방침

시행일: 2026-10-07

수집하는 정보

Daily Memo는 개인정보를 수집하지 않습니다. 사용자가 작성한 메모와 설정은 사용자의 브라우저 안에만 저장되며, 개발자나 제3자에게 전송되지 않습니다.

저장 위치

  • 기본: 크롬 확장 프로그램 전용 저장소(chrome.storage.local)에 저장됩니다. 사용자의 PC를 벗어나지 않습니다.
  • 동기화를 켠 경우에만: 크롬 동기화 저장소(chrome.storage.sync)를 통해 같은 구글 계정으로 로그인한 사용자의 다른 크롬 브라우저에 전달됩니다. 이 과정은 구글의 크롬 동기화 기능이 처리하며, 개발자는 접근할 수 없습니다.

사용 권한과 목적

  • storage, unlimitedStorage: 메모와 설정을 브라우저에 저장하기 위해 사용합니다.
  • contextMenus: 웹페이지에서 선택한 글을 우클릭 메뉴로 오늘 메모에 추가하기 위해 사용합니다. 선택한 텍스트와 해당 페이지 주소만 메모에 기록되며 외부로 전송되지 않습니다.

외부 서비스

이 확장 프로그램은 외부 서버와 통신하지 않으며, 분석 도구나 광고를 포함하지 않습니다.

데이터 삭제

메모는 앱 안에서 언제든 삭제할 수 있고, 확장 프로그램을 제거하면 저장된 모든 데이터가 함께 삭제됩니다. 백업이 필요하면 설정의 내보내기 기능으로 파일을 저장할 수 있습니다.
