## 상세 설명
아이콘을 누르면 오늘 날짜의 메모장이 바로 열립니다. 쓰는 대로 자동 저장되고, 메모는 날짜별로 정리됩니다.

• 오늘 메모가 바로 열림 — 아이콘 클릭 또는 Alt+Shift+M
• 자동 저장 — 저장 버튼이 없습니다
• 날짜별 정리 — 달력에서 날짜를 눌러 그날 메모로 이동
• 검색 — 지난 메모를 본문으로 검색, 일치 부분 강조
• 서식 — 글자를 드래그하면 굵게 · 형광펜(노랑/빨강/초록) · 크기 버튼이 나타남
• 이모지 — 자주 쓰는 이모지 10개를 버튼으로
• 웹페이지에서 담기 — 글을 드래그하고 우클릭 → "오늘 메모에 추가"
• 백업 — 기간을 골라 JSON(복원용) 또는 텍스트로 내보내기, 가져오기
• 동기화(선택) — 같은 구글 계정의 크롬끼리 메모 공유
• 창 크기 조절, 글자 크기, 다크 모드 자동 대응

데이터는 사용자의 브라우저에만 저장되며 외부로 전송되지 않습니다.

## 단일 목적 설명 (Single purpose)
날짜별로 메모를 작성하고 검색하는 메모장입니다.

## 권한 사용 근거
- storage: 메모와 설정을 브라우저에 저장합니다.
- unlimitedStorage: 오래 사용해도 메모가 10MB 한도에 걸리지 않도록 합니다.
- contextMenus: 웹페이지에서 선택한 글을 우클릭 메뉴로 오늘 메모에 추가합니다.
- 원격 코드: 사용하지 않음
